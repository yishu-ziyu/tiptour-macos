## 证据

### 2026-09-23 晚：原型，未改产品代码

用户要求先看样本应用到 Her 之后的样子，确认后再改。原型：`out/design/her-first-run/index.html`（git 忽略；`ThinkingOrb` 用原版 `thinking-orbs@0.3.1` 引擎内联绘制，MIT 许可证放在旁边）。四个场景：首次打开、设置好了、说话中、让她做事；可切换浅色/深色。

Notion 设计库（授权后另起只读进程读取；未找到名为「Will's S Design Note」的页面，读的是顶层设计库 Apple Design / Refactoring UI / NNGroup）给出的约束，原型据此改了结构：
- 推迟非必要设置、权限在第一次用到时再申请：首次设置从 4 步减为 2 步（存阶跃密钥、允许麦克风）；名字由她在第一次对话里问；「屏幕录制」在第一次问屏幕时就地申请。
- 空状态要说明下一步并给直接入口：设置好后的面板只放 ⌃⌥ 用法和三句可直接说的话，点一句即演示。
- 浮动面板用薄材质，状态用低调动效；避免「加载中」这类含糊词。

自查：无头 Chrome 截图四个场景和深色模式。发现并修复：光标旁气泡被外层 20px 容器压成逐字换行；浅色表面上 `ThinkingOrb` 对比度过低（原型中加深墨色）；菜单栏 SF Symbols 私有字符显示为方块；面板上「设置」出现两次。尚未经用户确认。

### 2026-09-24：原型落到产品代码（第 1、2 块），待用户在 Xcode 构建后验收

用户确认原型风格（「就定这个版本」）。本轮实现：
- 面板：系统薄材质（`.popover`），跟随浅色/深色；从状态栏下的药丸展开（先缩到 94% 95 ms，再 480 ms 铺开，行依次淡入，减少动态效果时直接出现）；标题栏只有 `ThinkingOrb`、名字和对话中的状态片。
- 设置好后的面板：⌃⌥ 键帽（可点，等同按下）、三句可以直接说的话、对话中的转写、回执、缺少的权限。「自动点击」移到 设置 → 连接，「固定面板」「查看日志」移到 设置 → 高级；面板上不再出现 TipTour 字样。
- 首次设置 2 步：存密钥（带「去阶跃开放平台获取」链接）→ 允许麦克风和辅助功能。与原型的差别：原型第 2 步只有麦克风；实际 ⌃⌥ 是事件监听，macOS 只对有辅助功能权限的应用送达，所以辅助功能必须在第一次对话前给。屏幕录制暂时放在面板的权限行里，第 3、4 块做完后改为第一次问屏幕时当场申请。名字暂在 设置 → Models 修改，第一次对话里起名是第 3 块。
- 取代 06R 规则：钥匙串里存在但本次进程还没读过的密钥（`.saved`，每次重启都是这个状态）以前会让面板回到设置第 4 步；现在显示设置好的面板，密钥在开始对话时真正读取，失败由会话报告。
- 光标旁的提示改为中文。

证据（辅助，不是验收）：`typecheck-local-app.py` `TYPECHECK_EXIT=0`，新文件无警告；`test-jev` 16 项、`test-stepfun-voice-lifecycle` 30 项、`test-stepfun` 18 项通过。未在真实构建上截图；U1–U4 待用户验收。
