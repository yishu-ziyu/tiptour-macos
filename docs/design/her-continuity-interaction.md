# 收起后回来接着做：交互状态契约

## 目标场景

在用户已认可的聊天真实素材上，演示她既能继续跟进旧事，也能发现新东西：用户收起窗口；期间样例出现一条项目进展和一条相关的动效发现；Her 给出无声、轻量的提示，不抢焦点、不自动展开；用户回来后能看懂变化为何与自己有关、来源在哪里，并能接着做。

这是交互样机契约，不是生产能力说明。聊天上下文可以取自已认可的真实素材；检索、执行和新消息均为明确标注的模拟事件。样机不启动真实监控、轮询或自动任务，不向外发送消息，不把建议说成已执行，也不承诺 Her 已有这些能力。

## 状态字段

| 字段 | 含义与约束 |
| --- | --- |
| 关注事项 | 用户当前想继续跟进的项目、问题或主题；展示其来自哪段已认可的聊天内容。不是订阅或后台监控授权。 |
| 上次看到哪里 | 最近一次用户实际看过的消息、进展或步骤锚点；收起、关闭和重载都不能把它推进到未读内容。 |
| 新变化身份 | 每条变化的稳定样例 ID，并带来源、来源内条目 ID、版本或时间；旧事进展与新发现分别成条。重载重放同一 ID 不算新变化。 |
| 提醒过未 | 按变化记录是否已显示过收起期间的独立轻提示。提示仅表示界面出现过，不代表已读；持续显示的未读计数是入口，不反复触发轻提示。 |
| 看过未 | 按变化记录未读/已读。样机只在用户主动打开该条详情时标为已读；提示和汇总列表出现、窗口关闭或重载都不改变它。 |
| 窗口状态 | 展开、收起或关闭。收起/关闭只改变窗口，不清空关注事项、不标已读、不表示完成，也不能触发自动重开。 |
| 完成状态 | 进行中/已完成。只在用户明确完成，或样机展示了可核对的完成回执时变化；关闭窗口、读过提醒、收到建议都不算完成。 |

这些字段彼此独立：可以窗口已关闭、已提示、仍未读、事项仍进行中。界面不能把它们压成一个“已处理”状态。

## 交互规则

1. 用户收起或关闭窗口后，保留关注事项与上次看到哪里；窗口不因模拟变化而自行展开。
2. 样机明确注入两条变化：一条旧项目的进展，一条按关注事项关联的新动效发现。每条都显示自己的变化身份、时间和来源；新发现须用简短文字说明关联依据，不能只靠排序或颜色暗示相关。
3. 窗口收起期间只出现无声、低存在感的提示（例如菜单栏未读标记）；不得播放语音/提示音、抢键盘焦点或切换当前应用。提示后保持原窗口状态。
4. 用户主动回来打开后，按“继续跟进”和“新发现”呈现未读变化，给出为什么相关、来源和时间。可继续查看或提出动作建议；建议动作在用户明确确认前不执行。
5. 项目进展使用带稳定 ID 的模拟变更记录；相关发现使用真实本地素材和原始出处，但到达时机是模拟的。样机不验证远端来源当前状态，不声称任何真实项目刚发生了变化。
6. 重载后按稳定变化身份去重，保留提示、已读和完成状态；同一变化不得重复计数或再次提示。用户离开后再回来仍回到未读位置；仅实际查看对应变化才转为已读。
7. 新消息不改变已有任务的状态。进入建议的任务草稿与确认执行是两个步骤；收藏一份发现不会自行启动任务。

## 用户可观察验收

由用户直接操作样机判定；脚本、截图或状态值本身不能替代体验。

| # | 操作 | 通过条件 |
| --- | --- | --- |
| 1 | 从已认可的聊天素材选定关注事项与上次看到的位置，收起再回来 | 两项上下文保留；窗口只在用户主动返回后展开，未读位置没有被推进。 |
| 2 | 在收起期间注入一条项目进展和一条相关动效发现 | 两条变化身份不同，各自显示来源与时间；新发现说明与关注事项的具体关联。 |
| 3 | 收起状态下，在演示工作草稿里持续输入并等待提示 | 出现无声轻提示；草稿的输入焦点和值不变，Her 未自动展开。仅验证样机内焦点，不据此声称真实 macOS 应用间行为已通过。 |
| 4 | 重载样机，再离开并返回 | 同一变化不重复；已提示、未读和未完成状态保留；回来能继续看到原位置。 |
| 5 | 主动打开并查看两条变化，再关闭窗口 | 看过的变化转为已读；关闭不替其他变化标已读，也不把关注事项标为完成。 |
| 6 | 查看项目进展或相关发现的来源 | 项目记录明确为模拟且有稳定身份；发现显示真实原帖链接，不冒充实时抓取，也不声称素材首次被发现的真实时间。 |
| 7 | 收藏发现或准备验证草稿 | 收藏不执行任务；准备草稿后仍需明确确认，未确认时没有执行状态或完成回执。 |

## 本轮文档落点

本契约只约束这次交互样机；方向同步在 [产品准则](../PRODUCT.md) 和 [路线图](../ROADMAP.md)。真实语音打断、系统通知、非激活面板、跨进程焦点与后台监控均不在本轮实现范围。

编辑源位于当前聊天的可视化目录：`her-material-room.source.html` 保留原素材交互，`her-continuity.js` 与 `her-continuity.css` 承载离开与返回的状态和视图；`build-her-room.cjs` 内联素材生成展示文件，`check-continuity.cjs` 保存用户路径的截图和 JSON 验证记录。这些文件不是应用运行时，也不参与 macOS 构建。
