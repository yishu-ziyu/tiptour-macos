# 语音重做验收

范围：阶跃语音客户端、采集与播放、管理器生命周期、中文状态与错误提示。不是全产品功能验收。

## 独立复核

1. `bash scripts/test-stepfun-voice-lifecycle.sh`：真实客户端/会话源文件隔离编译，14 项状态测试通过；迟到音频不得复活被打断响应。
2. `bash scripts/test-stepfun.sh && bash scripts/test-jev.sh`：14+12 项规则回归通过。
3. Xcode 的 `tiptour-macos` scheme 构建成功；不得将隔离 parse 成功当完整构建成功。
4. 阅读客户端：音频与控制消息通过同一个串行发送队列；握手失败须返回真实错误。
5. 阅读会话：麦克风在模型播放期间继续上传；使用 Voice Processing 消回声，启用失败报错而非静默降级半双工。
6. 阅读会话：response.done 仅表示生成结束，工具续轮须等待播放队列排空；stop/插话撤销旧工具结果。
7. 阅读管理器：StepFun 不读 Gemini key；开始/停止任务受身份保护；失败后下一次点击能重试；纯对话不依赖桌面控制权限。
8. 真机：点击开始显示连接状态，能听到一句完整回答，连续三轮；插话后旧回复不继续播，停止后麦克风不继续上传。**尚未通过，不用构建或单元测试替代。**
9. 真机：缺钥匙串访问许可或麦克风权限时出现明确提示；不宣称签名一致即所有系统授权永久有效。

## 证据

- 独立 reviewer 审查并修复：打断后迟到音频复活、启动失败僵尸会话、取消握手资源释放；新增回归。
- 构建由 Xcode AppleScript `build workspace document` 发起，不调用终端 xcodebuild。
- App 支持 `--show-panel` 和重新打开时展示面板，不自动开始录音。
